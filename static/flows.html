评测流程只看怎么跑返回平台

RAG

1准备题集在平台维护问题和参考答案。
2重新检索生成被测后端的各模式答卷。
3运行等待完成，在页面查看答卷和报告。
修改题集或检索参数后，重新检索再运行。

LLM

1添加模型填写模型名、地址和密钥。
2检测确认端点可用。
3运行选择基准和题数，等待结果。
真实运行可能产生 API 费用，先用少量题确认链路。

智能体

1启动服务在平台外启动你的 Agent。
2保存并检测至少提供 /health 和 /run。
3跑任务先试跑，再生成轨迹并运行。
红队扫描还需要 Agent 提供 /chat。

红队

1确认 Agent 在线检查接入地址。
2维护用例写清输入和通过条件。
3扫描查看通过和未通过的用例。
未通过表示发现需要处理的行为。
