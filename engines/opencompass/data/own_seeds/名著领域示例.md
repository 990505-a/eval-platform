# 名著领域示例种子

这是一份示例种子语料,演示合成出的自有题库长什么样。换成你自己的项目时,把本文件替换成你的业务文档即可。

《红楼梦》原名《石头记》,清代曹雪芹著,前八十回为曹雪芹所著,后四十回一般认为由高鹗续写。全书以贾、史、王、薛四大家族的兴衰为背景,以贾宝玉与林黛玉、薛宝钗的爱情婚姻悲剧为主线,展现了封建末世的社会图景。大观园是为迎接贾元春省亲而修建的省亲别墅,元春省亲后命宝玉与诸姊妹入园居住,园中主要居所有怡红院(宝玉)、潇湘馆(黛玉)、蘅芜苑(宝钗)、稻香村(李纨)等。

《三国演义》全名《三国志通俗演义》,元末明初罗贯中所著,是中国第一部长篇章回体历史演义小说。桃园结义为全书开篇:刘备、关羽、张飞在涿郡张飞庄后桃园中祭告天地,结为异姓兄弟,誓曰"不求同年同月同日生,只愿同年同月同日死"。全书围绕魏、蜀、吴三方势力斗争展开,官渡之战、赤壁之战、夷陵之战为三大关键战役。

《水浒传》元末明初施耐庵著,以北宋末年宋江起义为题材。全书前七十回以人物列传形式展开,鲁智深(花和尚)、林冲(豹子头)、武松(行者)等一百单八将先后被逼上梁山,聚义忠义堂,后排定三十六天罡、七十二地煞座次。

《西游记》明代吴承恩著,取材于玄奘取经故事。孙悟空出世后拜菩提祖师学艺,大闹天宫被如来压于五行山下,后经观音点化保护唐僧西天取经,与猪八戒、沙僧一路降妖伏魔,历经九九八十一难,终成正果,被封为斗战胜佛。

莎士比亚为英国文艺复兴时期剧作家,代表作四大悲剧为《哈姆雷特》《奥赛罗》《李尔王》《麦克白》,四大喜剧为《仲夏夜之梦》《威尼斯商人》《第十二夜》《皆大欢喜》。《哈姆雷特》中"生存还是毁灭,这是一个值得考虑的问题"为名句,主角丹麦王子哈姆雷特为父复仇的故事。
