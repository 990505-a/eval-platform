# 自有题库 · 种子语料目录

AI 合成题目(🎓 LLM 基准页 →「🧩 自有题库」→「AI 合成」)从这里随机抽材料块作为出题依据。

## 用法

- 把你项目相关的文档放进本目录:`.txt` / `.md` 均可,一个文件一个主题(如 `产品手册.md`、`工单归档.txt`、`领域规范.md`)
- 合成时每个文件随机抽一块 800-4000 字的材料 → LLM 依据它出选择题,**材料原句会作为锚(basis)附在待审题里**,审核时逐题核对
- 没有种子的空目录无法合成;示例文件 `名著领域示例.md` 可删

## 约定

- 采纳后的题落 `engines/opencompass/data/own/own.jsonl`(字段 question/A/B/C/D/answer),可在网页直接增删
- 用「自有题库」基准(bench key: `own`)跑分,与 C-Eval 等共用同一套模型登记与成绩矩阵
