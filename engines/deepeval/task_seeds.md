# 智能体任务合成 · 种子文件

`synth_tasks.py` 从本文件读取「工具清单」与「领域素材」两个段落, 结合现有任务示例(few-shot)
让 LLM 生成新任务草稿 → 待审区(🤖 智能体测评 →「任务集」)→ 人工采纳后进入正式任务集。

**换成你自己的智能体时只需改这份文件**:工具清单照抄被测智能体注册的工具名和描述,领域素材放业务背景/素材。
下面的工具名只是示例(与接入指南里的参考智能体一致), 必须改成你自己的。

## 工具清单

- web_search: 联网搜索资料。输入为具体检索问题, 返回相关摘要。回答事实类问题前必须先调用本工具。
- write_file: 把内容写入工作区文件(path 为相对路径, 如 报告.md)。产出交付物时使用。
- read_file: 读取工作区文件内容(相对路径)。
- save_memory: 把重要信息写入长期记忆(文件 memory/long_term_memory.md, 跨对话持久)。用户表达偏好/约定时使用。

## 领域素材

被测智能体是一个通用助理智能体(示例配置)。
典型场景: 检索资料并引用来源作答; 把调查结论写成工作区报告文件; 把用户偏好写入长期记忆;
先读旧报告再续写。任务应多样化: 单工具检索型、检索+写文件组合型、记忆型、读文件+综合型。
